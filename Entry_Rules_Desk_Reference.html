Trading Program — Long & Short — US & UK Equities
Process Over Prediction  |  Discipline Over Activity  |  Compounding Over Excitement
LONG — 3 GATES (All Must Pass or REJECT)
1
Trend Template — Price > 50/150/200 MA; MAs stacked up; 200 MA rising ≥ 1mo; ≥ 25% off 52wk low; within 25% of 52wk high; RS ≥ 70. Any fail → KILL
2
ADX(14) > 25 — Confirms genuine trend, not chop. Below 25 → KILL
3
Volume Dry-Up — ≥ 2 of last 5 sessions with volume < 60% of 50d avg. No dry-up → KILL

SHORT — 3 GATES + SQUEEZE CHECK (All Must Pass or REJECT)
1
Inverse Trend Template — Price < 50/150/200 MA; MAs stacked down; 200 MA falling ≥ 1mo; ≥ 25% off 52wk high; within 25% of 52wk low; RS ≤ 30. Any fail → KILL
2
ADX(14) > 25 — Confirms downtrend momentum. Below 25 → KILL
3
Distribution Days — ≥ 3 of last 10 sessions closing down on volume ≥ 1.25× avg. No distribution → KILL
4
Squeeze Check — SI < 20%, Days to Cover < 5, Borrow fee < 5% annual. Any fail → KILL
CLIMAX TOP (S-D) EXCEPTION: Replace Gate 1 with: stock up ≥ 100% in 8 wks + widest range + highest volume + close in lower 25% + extended ≥ 50% above 200 MA. All 5 must be TRUE.

EXECUTION RULES (BOTH SIDES)
VOLUME CONFIRMATION: Breakout/breakdown session must show volume ≥ 1.4× 50d avg. Mid-session check: if projected vol < threshold → reduce to 50% pilot. EOD vol < threshold → close pilot.
SCALING — 2 TRANCHES:
T1 = 60% at primary entry. T2 = 40% on follow-through only if T1 is in profit.
NEVER average into a loser. If T1 underwater → T2 is BLOCKED.
ORDER TYPES:
Breakout/breakdown → Stop-limit  |  Pullback/rally → Limit  |  Gap → Limit on pullback or stop above/below OR
UK spread > 0.3% → Limit only, reduce 25%  |  UK spread > 0.5% → SKIP
GAP RULES:
Long BGU: Early-stage only (1st/2nd base). Late-stage gap = exhaustion = DO NOT BUY.
Short SGD: Late-stage only. Early-stage gap down = possible shakeout = DO NOT SHORT.
Both: Wait 15 min for opening range. Failed gap → 3-day reclaim window, then quarantine.

OVERNIGHT & CATALYST PROTECTION
EARNINGS: Auto-exit/cover EOD before report. No exceptions. No "this time is different."
BINARY CATALYST: (FDA, legal, etc.) Reduce to 50% or exit EOD prior.
SECTOR CORRELATION: ≥ 3 positions same sector → reduce each to 75%.
UK-SPECIFIC ADJUSTMENTS
AUCTION: Limit orders only into open (07:50–08:00 GMT). No market orders.
STAMP DUTY: +0.5% on long purchases (shorts exempt). Factor into breakeven.
CFDs: Longs < 10-day hold → CFD avoids SDRT. UK shorts → CFD or spread bet required.
AIM: Limit orders only, always. Check depth before every order.
DECISION FLOW (BOTH SIDES)
→ Signal received (Long or Short)
→ Gate 1: Trend Template (or Inverse) — Fail = REJECT
→ Gate 2: ADX > 25 — Fail = REJECT
→ Gate 3: Volume (dry-up for longs / distribution for shorts) — Fail = REJECT
→ Gate 4 (shorts only): Squeeze/borrow check — Fail = REJECT
→ Classify entry type → Apply gap rules if applicable
→ Risk budget check (1% trade, 6% total, stop ≤ 8%, short cap 50%) — Fail = SKIP
→ UK spread check — > 0.5% = SKIP
→ PLACE T1 (60%) → Volume confirm → T2 if T1 in profit → LOG
